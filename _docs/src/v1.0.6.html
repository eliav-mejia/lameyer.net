Versión 1.0.6 — Medidas de seguridad

Revisión de seguridad del entorno de desarrollo y del sitio público. Este documento resume el alcance y el enfoque; el detalle técnico se mantiene en la documentación interna de Lameyer y no se publica.

Por qué un resumen. Publicar configuraciones, hallazgos o pruebas de seguridad facilita el trabajo a quien quiera atacar el sitio. Por eso esta edición explica qué se revisa y cómo se trabaja, pero no el estado concreto de cada control.

1Alcance

Desarrollo

Cómo se escribe, revisa y publica el código: entorno de trabajo, control de cambios y revisión antes de publicar.

Sitio público

Cómo se sirve el sitio y qué datos intercambia el navegador con Lameyer y con terceros.

Cuentas

Cómo se gestionan el acceso y los datos de las personas usuarias antes de pasar a un servicio de cuentas definitivo.

2Enfoque

  • Defensa en capas. Ninguna medida aislada se considera suficiente; cada capa asume que la anterior puede fallar.
  • Mínimo privilegio. Cada persona, herramienta y servicio tiene solo el acceso que necesita.
  • El navegador no es fuente de verdad. Precios, stock y pedidos se confirman siempre del lado de Lameyer.
  • Privacidad. Los datos enviados a terceros se reducen al mínimo y se informan en los términos.
  • Verificación. Una medida se da por hecha solo cuando su comprobación está registrada.

4Cómo informar de un problema

Si encuentras un posible problema de seguridad, escríbenos a contacto@lameyer.net con el asunto «Seguridad». No lo publiques hasta que te respondamos.
